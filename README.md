# Instructions for Running this Project

1. Open this project in IntelliJ IDEA.
2. Open `application.properties` found in `group-32/SkillsBuildGamification/src/main/resources/application.properties`
and assign `spring.datasource.url`, `spring.datasource.username` and `spring.datasource.password` to the values used in your local MySQL database.
3. Run the project by clicking the "gradle" tab on the right of the editor, then running "bootRun" found in `SkillsBuildGamification/Tasks/application/bootRun`
4. Open Google Chrome and navigate to <https://localhost:8443/>
5. You should see the login page.
6. Refer to the user manual found in `group-32/UserManual/User-Manual.docx`
